# memory/red-black-review —— 红黑队私有记忆

本目录是 `red-black-review` 技能的**记忆写入区**，只存本项目私有产物，换项目时清空内容、只保留本结构。

## learned/ —— 学习卡（飞轮写回）

每轮对抗结束必写一张学习卡；`T4 元层`触发时记录新攻击面/heuristic。
下一轮红方开跑前读取最近学习卡，把新启发并入攻击清单。

### 学习卡命名
`<yyyy-mm-dd>-<topic>.md`

### 学习卡模板
```markdown
# 学习卡：<topic>
- 日期 / 轮次 / 层级（T1–T4）
- 红方抓到/未抓到的错误类型（如：数字漂移、孤例、相关性≠支持、脑补……）
- 黑方改进（改了什么）
- T4 是否触发：若触发，新攻击面/heuristic 是什么
- 一句话可复用的清单项（新增或强化）
```

### 纪律
- 每轮**必写**；T4 触发**必记**新启发。
- 学习卡只记"真实失败/真实产出"，不记空泛心得。
- 被后续轮次验证有效的新启发 → 可回填进 `SKILL.md`（再固化一层）。

## weapons/ —— 私有武器（飞轮写回）

存放 L0 之外的 L1/L2 私有武器，由主 agent 在打磨过程中写回：

- `weapons/L1-weapons/`：L1 级武器（量级快筛 / 通用启发）。
- `weapons/L2-weapons/`：L2 级武器（更深攻击面 / 领域专属启发）。
