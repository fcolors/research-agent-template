# 同行评审（Peer Review）——审稿人角色

以审稿人身份，对给定文本给出**专业、中立、可执行**的评审意见。这不是"挑毛病比赛"，而是帮助作者把工作提升到可发表标准的建设性评审。

## 评审报告结构（最重要在前）

按以下顺序组织评审意见：

1. **总体印象与摘要**：这段/这篇工作做了什么？对读者/领域有什么意义？一段话。
2. **主要优点**：明确列出值得肯定的点（方法、证据、清晰度、新颖性）。
3. **主要问题（Major）**：影响结论成立或不可接受的缺陷，逐条编号、指向具体位置。
4. **次要问题（Minor）**：措辞、格式、参考文献、小疏漏，逐条编号。
5. **具体行文意见**：按"位置—问题—建议"给出，能引用原文片段。
6. **推荐动作**：Accept / Minor revision / Major revision / Reject，并给出一句话理由。

## 评审检查清单（字段无关，适用任意学科综述；领域清单按项目在 `memory/` 中配置）

### A. 科学层面
- **新颖性与重要性**：相对已有综述/文献，本工作提供了什么新视角或新综合？
- **论证健全性**：每个关键论断是否被证据支撑？**主张→证据**的链条是否完整、无断层？
- **反向前置检查**：是否有"先有结论、再反向找证据凑"的痕迹？反向推断是否被如实标注？
- **局限与边界**：是否诚实说明适用范围、未覆盖的子领域、不确定性？
- **避免越界断言**：推断是否被写成事实？(如"有望""必然"等)

### B. 证据与文献
- **证据可追溯**：每个关键 claim 是否指向具体来源（论文+页码/章节+来源层级）？
- **文献覆盖**：是否引用了该领域应有/近年/权威的文献？有无关键遗漏或过度依赖单一来源？
- **孤例证明检测**：某章节的关键论断是否靠**单一来源**支撑多个论点？若有，属孤例证明，须补独立来源。
- **相关性≠支持检测**：引用是否“相关但未真正支撑该主张”（主题偏离）？例：用“自旋晶格论文”支持“强磁场谱学”。
- **近5年优先**：作为进展类综述，近5年文献是否充分？旧文献是否只作历史锚点？
- **来源类型标注**：established / interpretation / hypothesis / contested / unknown 是否分明？
- **对齐审计**：综述所用文献是否已入库/可追溯？未入库（如仅 arXiv id）须明确标记，不得冒充已核对文献。

### C. 范围与结构
- **范围恰当性**：应用/案例节是否过窄或过宽于综述主题？是否只覆盖作者熟悉区而遗漏领域全貌？
- **结构-证据匹配**：章节划分是否与“能支撑的证据”匹配？证据不足的章节是标记 GAP 还是硬写？

### C. 写作质量
- **清晰与组织**：结构是否逻辑连贯？段落是否有单一主旨？
- **用词规范**：术语是否统一、符合学科标准（见 review/_writing/academic-vocabulary.md 术语表）？有无口语化/口号化/同义反复？
- **叙述性**：若是综述，是否叙述脉络而非"优点—缺点—总评"逐篇点评？

## 语气与边界（PLOS/Elsevier 指南）

- 专业、尊重、中立；**把评论写给作者看**，用"作者需要澄清/请补充证据"而非攻击性措辞。
- 具体、可执行；每条意见给出"位置—问题—建议"，不空泛。
- 承认作者已做好的部分；主要问题必须有实质证据支撑，不因风格偏好而拒绝。
- 自己的不确定写为"需要作者澄清"而非断言错误。

## 输出模板

```markdown
# 评审意见（Peer Review）

## 总体印象
（2-3句：做什么、重要性、是否达到发表标准）

## 优点
1. ...
2. ...

## 主要问题 (Major)
1. [位置] 问题描述 — 为什么重要 — 建议
2. ...

## 次要问题 (Minor)
1. [位置] ...

## 证据链核验
- 每条关键 claim 是否可追溯？列出通过的 / 断链的。
- 反向推断是否被标注？
- **孤例证明**：哪些章节仅单源支撑？列出。
- **相关性≠支持**：哪些引用是“相关但未真正支撑”？列出。
- **对齐**：引用的文献哪些未入库（仅 arXiv id / 外部）？列出。

## 推荐动作
**Major revision** / **Minor revision** / **Accept** / **Reject**
理由（一句话）：
```

## 使用方式

- **红方角色**：在红黑队自审中，本 skill 即红方——假设文本有问题，按清单逐条攻击，给证据或认账。
- **独立审稿**：对某段落/整章跑本 skill，产出结构化评审，作者据此修改。
- **训练校准**：用公开审稿意见/审稿指南（如 PLOS 的 How to write a peer review）对照本 skill 的输出，校准评审质量。
