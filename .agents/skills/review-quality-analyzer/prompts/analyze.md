# 科学分析提示词 v2（子代理 A：读原文、出深度分析）

> 目的：让子代理以**科研的方式**读一篇论文——**先想它如何实现、能做什么，再谈价值**——产出达到高质量综述水准的深度分析，而非"直接陈述它是什么"。
> 使用：把这个模板 + 待分析的论文全文 + 论文所在综述块的引用上下文 一起喂给子代理 A。

## 任务
以**科研的认知顺序**分析下面这篇论文的**实际内容**（读全文，不只读摘要），按下列四层输出。
核心纪律：**先有"如何实现/能做什么"，再谈价值**——不要在还没讲清机理和能力之前就下价值判断。
段内纪律：**每一段内部也遵守"先机制/手段、后结果/价值"**；若某条先写了结果，必须重排为先给支撑机制；在给出支撑机制/手段之前，禁止任何能力或价值陈述。

## 输入
- 论文全文：`<PASTE_FULLTEXT_OR_PATH>`
- 它在高水平综述中的位置/被综述怎么用的：`<PASTE_REVIEW_BLOCK>`

## 输出四层

### 1. 它是如何实现的（机制 / 方法 / 工程）？
- **物理机制**：核心物理/化学/生物机制是什么——用"为什么能做到"的语言，讲清关键物理量与结果之间的因果链，不要只报"做到了什么指标"。
- **装置/方法/仪器工程（必答，不许略过）**：装置/方法如何实现关键量的定位、稳定与测量——灵敏度来源、反馈/无反馈取舍、噪声与干扰隔离的层级、关键部件/材料制备、实验条件各自的作用；必须给出"敏感度→稳定度需求→达成手段"的**定量预算链**（例：某关键量每变化 X 会导致结果变化 Y，因此要把该量的漂移控制在 Z 以内），禁止只报"精度达到多少"之类结果数字。
- **关键方法与工艺细节**：装置/方法怎么搭、参数、数据处理、噪声/漂移怎么控；工程上"把不可靠变可靠"的折中（如冷却/锁定/屏蔽等稳定手段）及其代价。

### 2. 它能做什么（能力 / 测什么量 / 达什么性能）？
- 每条能力必须写成"**因为 §1 的哪个机制/手段，所以能测到/做到 X**"，禁止只报"测到了 X"。
- 每条同时给"**理想/上限 → 实际达到 → 代价或折中 → 为什么难**"四件套（定量：能量分辨、空间分辨、磁场、温度、操控对象、时标等）。
- 它解锁了哪一类测量/构筑/操控能力；能力背后的"原理支撑"（为什么能测到这些，而不是碰巧）。
- 写完逐条自检回链：没有回链到 §1 的条目删掉或改写。

### 3. 证据与局限（批判性，就地给）
- **就地给**：在每条机制/能力处就地标注证据强度（established / preliminary / interpretation）与局限、代价，并把"推断写成事实""相关性≠支持"处就地指出来；本节只做收束性总结，不重复铺陈。
- **元层面批判（若该文献是综述/评论，强制做）**：它把哪些异质成果顺滑串成"演化链"？是否系统放大某一组/作者自己团队的贡献（检查引用密度与叙述重心）？有没有把"间接推断"埋在文末、而非用来限定全文结论？至少给出一条"它为什么这么写、这掩盖了什么"。
- 若原文某处没讲，如实标"原文未明说"，不脑补。

### 4. 一句话（放在整个领域的意义）
- 它在"成像→构筑→验证→功能→自动化"这条演化链上解锁了哪一步。
- 只在这四层都讲清后，才允许一句价值判断。

## 纪律
- **读原文**，不摘摘要词；给出具体数字、机制、细节。
- **叙事形式**：全文用**连续论证段落**书写——每段一句主张 + 2–3 句论证，靠因果连接词串起；**禁止用"冒号+分号+子弹"拼装清单**；只有并列实例、且每个实例都已单独展开过时，才允许一个紧凑列表收束。完成后通读一遍，凡有"罗列感"的段落必须改写成论证段。
- **数字性质就地标注**：每个数字就地内联标注其性质——实测/计算/拟合/设定/稳定度/上限，并区分理想值与实际达到值；未标注的数字视为不合格。
- **深度优先**：宁可少写几个例子，也要把每个例子"讲透一句"；不要用广度换深度。
